# Security policy

## Supported versions

CoreBall is pre-1.0. Security fixes are provided for the latest released version.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities. Email the maintainers at security@example.com with:

- A description of the issue.
- Steps to reproduce.
- Potential impact.
- Suggested mitigation, if known.

We will acknowledge receipt within 7 days and provide a follow-up timeline.

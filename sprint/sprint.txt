# CoreBall v0.1 sprint

Cycle: analysis, development, validation, tuning.

## Analysis

- Define CoreBall as a semantic compiler for repository context.
- Keep v0.1 focused on deterministic, useful repository inspection and task-aware packing.

## Development

- Implement Python package and CLI.
- Add parsers, graph inference, selector and renderers.
- Add public documentation and GitHub release assets.

## Validation

- Run install, formatter, linter, type checks, tests, CLI examples and package build.
- Fix every failure before declaring v0.1 complete.

## Tuning

- Improve ranking, excerpt quality and docs based on validation results.
